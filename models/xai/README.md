# xAI Models

This recipe demonstrates how to use xAI's Grok models with Spice.ai.

[![Watch the Spice.ai LLM memory demo](https://img.youtube.com/vi/-7RkAsqQLdk/hqdefault.jpg)](https://www.youtube.com/embed/-7RkAsqQLdk)

## Prerequisites

1. An xAI API key (get one from [x.ai](https://x.ai/api))
2. Spice CLI installed ([Getting Started Guide](https://docs.spiceai.org/getting-started))

## Configuration

1. Update the `.env` file with your xAI API key (or edit directly in the `spicepod.yaml`).

## Run

1. From the recipe directory, start the Spice.ai runtime:

```shell
spice run
```

2. Open another terminal and run `spice chat`:

```shell
spice chat
```

3. Ask a question.

```text
chat> Who are you and who made you?
```
